Eduly — Release secrets (REPO DIŞI)
=================================
Bu klasör git'e ASLA eklenmemeli.

İçerik:
- upload-keystore.jks          → Play yükleme imzası (KAYBETME)
- UPLOAD_KEYSTORE_CREDENTIALS.txt → şifreler + SHA
- upload_certificate.pem       → Play Console referans sertifikası
- key.properties               → Gradle imza config

Önerilen ek yedek: 1Password / şifreli USB / Google Drive (özel klasör).

APNs (.p8) buraya ayrıca koy: AuthKey_XXXXX.p8 + Key ID + Team ID notu.
